# CodeQuest

Trilha gamificada de lógica de programação em Python com a Profª Joanne.

Para executar localmente, use `python -m http.server 8000 --directory dist` e abra `http://localhost:8000`.

O diretório `dist/` contém o site, `database/` contém o esquema Supabase e `docs/` reúne o planejamento e a matriz curricular.
